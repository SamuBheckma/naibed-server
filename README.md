## Desenvolvimento local

Abra `index.html` no navegador ou inicie um servidor estático na raiz do projeto:

```sh
python -m http.server 8000
```

Depois visite `http://localhost:8000`.

## Publicar com GitHub Pages

No repositório, abra **Settings → Pages**, escolha **Deploy from a branch**, selecione `main` e a pasta `/ (root)`. O site será publicado pelo GitHub Pages sem processo de build.

## Estrutura

```text
index.html       conteúdo e estrutura semântica
styles.css       identidade visual responsiva
script.js        menu móvel, animações de entrada e ano do rodapé
assets/mark.svg  favicon vetorial
```

## Privacidade

O site é estático e não possui backend, login, analytics, formulários ou armazenamento de dados pessoais. Nenhum arquivo `.env` ou credencial é necessário.
